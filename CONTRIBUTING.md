# Contributing to Heir Unlocker

This repository manages desktop application release verification, platform builds, installers, checksums, and signing key distribution for Heir Unlocker.

## How to Contribute

- **Platform Testing:** Verify `chronolox-heir` on untested distributions, macOS versions, or Windows configurations.
- **Verification Tooling:** Propose improvements to checksum verification scripts or installer packages.
- **Reporting Issues:**
  - For suspected corrupted archives or checksum discrepancies, open an [issue](https://github.com/Chronolox/heir/issues).
  - For security vulnerabilities, do NOT open a public issue. Follow [SECURITY.md](./SECURITY.md) and email `security@chronolox.com`.
